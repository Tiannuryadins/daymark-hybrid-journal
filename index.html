How the hybrid works

On-device — Gemini Nano 4
In desktop Chrome (139+), quick reflections run entirely in your browser via the Chrome Prompt API. Private, free, and it works offline. Your words never leave the device.
Cloud — Gemini Flash
When Nano isn’t available, Firebase AI Logic falls back to Gemini in the cloud, and the weekly insight always starts there — long context is a cloud job.
You can see the route
Every answer carries a badge showing whether it ran on-device or in the cloud, straight from the SDK’s inferenceSource. No guessing.

Built with Firebase AI Logic (hybrid inference), Firestore, Anonymous Auth and App Check. Entries are stored per anonymous user and protected by Firestore security rules.
